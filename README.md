# Детектор сигналу в умовах перешкод та завад
Алгоритм визначення активності сигналу та його реалізація на STM32G474RET6.

Розробка — [hopeok.com.ua](https://hopeok.com.ua/)

## Про оформлення тексту

Технічну документацію мені писати довго й важко, тому текст допомагав оформити
штучний інтелект. Розуміння алгоритмів, вибір рішень та реалізація проєкту —
виключно мої.

## Що в архіві

```

```

## Ключові файли

Алгоритм повністю міститься у двох файлах:

- **`Core/Src/SignalDetector.cpp`** — кінцевий автомат, оцінка рівня, стабільності
  та фону, гістерезис. Не залежить від периферії, тому перевіряється окремо;
- **`Core/Src/detector_app.cpp`** — конфігурація апаратного фільтра через регістри,
  зв'язок з АЦП і DMA, розподіл по задачах, телеметрія.

Решта файлів у `Core/` — стандартна ініціалізація, згенерована STM32CubeMX.

## Збірка

Проєкт відкривається в STM32CubeIDE. Для збірки без середовища розробки:

```
cd firmware
make            # шляхи до компілятора вказані у верхній частині Makefile
make flash      # прошивка через ST-Link
```

## Перевірка роботи

Джерело сигналу подається на вхід **A0** (пін PA0), рівень 0…3,3 В.

```
python tools/detector_monitor.py
```

Порт визначається автоматично, швидкість 921 600. Індикація активного стану
виведена також на світлодіод плати.

## Стан

Прошивку зібрано, залито та перевірено на платі NUCLEO-G474RE. Виміряні показники
наведені у звіті, розділ 4.
